Тест отладочной кнопки для iPad 5

Инструкции для тестирования на iPad 5:

  1. Откройте эту страницу на iPad 5-го поколения
  2. Кнопка "Показать геометки" должна появиться в правом верхнем углу
  3. Нажмите на кнопку - красные кружки должны стать видимыми/скрытыми
  4. Проверьте консоль браузера для отладочной информации

Тип устройства: Определяется...

Старый iPad: Определяется...

Видимость геометок: Скрыты
