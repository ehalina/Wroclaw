Тест Progressive Enhancement для планшетов

Информация о текущем режиме:

Тест 1: Кастомные курсоры

На планшетах курсоры должны быть видны всегда. На десктопе - только при наведении.

Наведите курсор (десктоп) или тапните (планшет)

Тест 2: Изображения

На планшетах изображения должны быть видны всегда.

Тест 3: Текстовые элементы

На планшетах текст должен быть виден всегда.

Этот текст должен быть виден на планшетах

Тест 4: Геометки

На планшетах геометки должны быть видны всегда.

Инструкции для тестирования:

  1. На планшете: Все элементы должны быть видны сразу при загрузке страницы
  2. На десктопе: Элементы должны скрываться и показываться только при наведении курсора
  3. На гибридном устройстве (Surface): Должен работать hover-режим
