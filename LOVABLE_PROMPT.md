# ПРОМПТ ДЛЯ LOVABLE.DEV - ВИРТУАЛЬНАЯ ЭКСКУРСИЯ ПО ТУМСКОМУ ОСТРОВУ

Создай интерактивную виртуальную экскурсию по Тумскому острову во Вроцлаве (Польша) - это туристическое веб-приложение с современной архитектурой на React + TypeScript + Tailwind CSS.

## 🏗️ АРХИТЕКТУРА ПРОЕКТА

**Технологический стек:**
- React 18 + TypeScript
- Next.js 14 с App Router
- Tailwind CSS для стилизации
- Framer Motion для анимаций
- React i18next для многоязычности
- Zustand для управления состоянием
- Supabase для данных (опционально)

**Структура проекта:**
```
app/
├── page.tsx                    # Главная страница
├── layout.tsx                  # Общий layout
├── tumski/
│   ├── page.tsx               # /tumski - главная экскурсия
│   └── [id]/
│       └── page.tsx           # /tumski/19 - конкретная локация
├── dwor/
│   └── [id]/
│       └── page.tsx           # /dwor/01 - дворы
├── ogrod/
│   └── [id]/

└── components/
    ├── InteractiveMap.tsx     # Интерактивная карта
    ├── Geomarker.tsx          # Геометки на карте
    ├── NavigationArrows.tsx   # Стрелки навигации
    ├── MusicPlayer.tsx        # Музыкальный плеер
    ├── LanguageSelector.tsx   # Переключатель языков
    └── ModalWindow.tsx        # Модальные окна
```

## 📱 PWA И ПОЛНОЭКРАННЫЙ РЕЖИМ

Создай полноценный PWA, который работает как иммерсивное полноэкранное приложение:

- Манифест (`web app manifest`) с режимом отображения `standalone`, темами и иконками всех размеров
- Service Worker: офлайн-кэширование основных страниц, изображений, аудио и переводов; стратегия кеширования: `Stale-While-Revalidate` для контента, `Cache First` для медиа
- На iOS использовать `apple-mobile-web-app-capable: yes`, скрыть браузерную хромину, запуск в полноэкранном режиме
- Учитывать `safe-area-inset` (вырезы/динамические острова), не перекрывать системные жесты
- Авто-блокировка скролла документа (фон всегда статичен), управление только внутри сцены
- Реакция на изменение ориентации и выхода/входа из полноэкранного режима

## 🧭 ПЛАВАЮЩАЯ НИЖНЯЯ ПАНЕЛЬ УПРАВЛЕНИЯ

Добавь лёгкую плавающую панель внизу экрана (всегда поверх сцены):

- Стиль: полупрозрачное стекло (glassmorphism), размытый фон, мягкая тень, округлые углы; высота ~56–64px; максимальная ширина 980px, центрирование; отступы с учётом `env(safe-area-inset-*)`
- Адаптивность: авто-скрытие при неактивности (через 3–4 сек) с плавным появлением по движению курсора/тача; на мобильных — минимальная высота и крупные касаемые области
- Кнопки (иконки + подписи по ховеру/долгому тапу):
  - Map — открыть карту (см. раздел «Карта»), по центру панели как основная action-кнопка (FAB-стиль, слегка приподнята)
  - Language — выбор языка
  - Music — вкл/выкл звук, управление громкостью, индикация текущего трека
  - Menu — меню со списком локаций/разделов и быстрым переходом
  - Quest — быстрый доступ к квестам/достижениям
- Доступность: фокус-стили, управление клавиатурой, ARIA-атрибуты, контраст

Панель не должна закрывать важные элементы сцены и геометки; при появлении — смещение/подъём подсказок, чтобы не перекрывались.

### Представление карты (как на скриншоте)

- Открывается поверх сцены в центрированном модальном окне с лёгким затемнением фона (backdrop-blur + dim)
- Стилистика «акварель/пергамент» с тонкой рамкой и лёгкими тенями; скруглённые углы
- Поддержка pinch-to-zoom и панорамирования; двойной тап — зум к ближайшей геометке
- Геометки на карте синхронизированы с сценой (ховер/клик подсвечивает соответствующую точку и в тексте)
- Кнопки в модальном окне: «Закрыть», «Центрировать на текущей локации», «Показать путь» (если применимо)
- Производительность: отложенная загрузка карты и тайлов/изображений, кэширование в SW
